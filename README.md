# 双通道任意波形发生器 V2

基于 Smart ZYNQ SL V1.3B（XC7Z020）和 ACM9767 的双通道 AWG 工程，包含 RTL、裸机固件、中文上位机、约束、构建脚本及验证资料。

请从 [完整中文说明](README.zh-CN.md) 开始，接线与运行步骤见 [快速开始](docs/quickstart.zh-CN.md)。移植代码和外部资料的来源列在 [第三方声明](THIRD_PARTY_NOTICES.md)。

当前的板级模拟性能、50 MSPS 接口时序及 DDR 长时间连续播放仍需实测；完成情况以 [构建与验收记录](docs/build_validation.zh-CN.md) 为准。
