# AWG V2 串口/TCP 协议

两种传输共用二进制帧。每帧为 20 字节小端帧头 `<4s BB H I I I>`，依次是魔数 `AWG2`、操作码、标志、状态、请求序号、负载字节数、CRC32，再跟随负载。最大负载 32768 字节。CRC-32/ISO-HDLC 覆盖帧头前 16 字节与负载，不包括帧头中的 CRC 字段。请求状态为 0；响应操作码为请求码 OR `0x80`，状态 0 表示成功。一个连接同一时刻只发一个未完成请求；重试必须保持请求序号和内容不变。

| 操作码 | 名称 | 请求负载 | 成功响应 |
|---|---|---|---|
| `01` | INFO | 空 | `<BIII>`：协议版本、通道数、当前采样率、每路最大点数 |
| `02` | STATUS | 空 | `<BBII>`：运行掩码、故障位、A/B 欠载计数 |
| `03` | CONFIG | `<BBB Hh QQ IH>`：通道 1/2、自定义标志、形状、Q15 增益、带符号偏置码、48 位频率字、48 位初相位、整数分频、空闲码 | 空；写影子参数 |
| `04` | APPLY | `<B>` 通道掩码 | 空；统一应用影子参数 |
| `05` | RATE | `<I>`：10000000/25000000/50000000 | 空；先停两路、清 FIFO 再切换 |
| `10` | BEGIN | `<BII>`：通道、点数、整段样点 CRC32 | `<II>` 上传 token、已收点数 |
| `11` | DATA | `<II>` token、起始点序号，随后为小端 uint16 样点 | `<I>` 下一点序号 |
| `12` | END | `<I>` token | 空；校验整段 CRC32 |
| `13` | COMMIT | `<B>` 通道掩码 | 空；所选通道全部就绪后统一生效 |
| `14` | QUERY | `<I>` token | `<I>` 已收点数 |
| `20` | ARM | `<BHB>`：通道掩码、周期数、外部触发标志 | 空；周期数 0=连续 |
| `21` | START | `<B>` 通道掩码 | 空；已布防且非外触发时同步启动 |
| `22` | STOP | `<B>` 通道掩码 | 空；任意会话可执行 |
| `23` | CLEAR | 空 | 空；只允许停止状态清故障 |

形状 `0/1/2/3` 分别为正弦、方波、三角波、锯齿波。样点有效值 `0～16383`；`16384～65535` 无效。自定义波形采用严格逐点顺序及整数分频；`长度 <= 16384` 时提交到双缓冲 BRAM，较长时由 DDR 循环 DMA 供数。单次或突发的样点数严格等于 `波形长度 × 周期数`，每个样点按分频保持指定采样周期。标准 DDS 周期按相位回绕计数。

错误状态：`1` CRC、`2` 长度、`3` 参数、`4` 状态、`5` 上传偏移/token、`6` 控制权、`7` 硬件、`8` 未知命令。异常或中断上传不能取代当前有效波形；重连后以相同通道、点数和整段 CRC 重发 BEGIN 可取得已有 token 与偏移。END 的整段 CRC 校验失败后，旧 token 作废；重新发送相同 BEGIN 会从偏移 0 获得新 token，当前已提交波形仍保持不变。一个设备只有一个进行中的上传；结束后的另一路上传可开始。控制权由一个会话占有，断开释放；STOP、INFO、STATUS、CLEAR 可由其他会话调用。故障位 `1` 欠载、`2` DMA、`4` 采样时钟失锁。
